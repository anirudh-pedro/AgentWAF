# 🛡️ Agent WAF - React SIEM Dashboard

Enterprise SIEM Operations Dashboard built with **React 18**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Recharts**.

---

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start Vite dev server
npm run dev
```

*Dashboard available at: `http://localhost:3000`*

---

## 🛠️ Build & Verification

```bash
# Type check and build Vite bundle for production
npm run build
```
